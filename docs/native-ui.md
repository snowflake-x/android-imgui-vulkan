# 原生分页、国际化与系统字体

主界面由 Dear ImGui 绘制，底部固定两项：**主页 / 插件列表**。每页有独立的内容滚动区；系统栏和开孔继续使用 NativeActivity contentRect 避让。切换页面不会加载或卸载插件，也不会启停采集会话。插件页启停动作仍在渲染帧边界提交，停用 HUD 会显式停止悬浮窗。

内容区支持手指直接纵向拖动，无需抓住滚动条；底部导航固定，每页保留自己的滚动位置。超过拖动阈值后取消按钮点击，避免滑动时误触。滑块、文本输入、弹出菜单和滚动条保留原有交互，鼠标滚轮仍可使用。手势由 C++ `ui/navigation.*` 管理，Android 触摸取消、失焦及配置变化时清除手势；当前为跟手滚动，不包含惯性滑行。

主页语言选择支持 **跟随系统、English、简体中文**。默认跟随 Android Resources.Configuration 的语言列表；当前提供英文和简体中文，中文区域使用简体译文，其余语言回退英文。系统语言或字号变化、应用重新获得焦点时刷新字体。设置保存到原生配置版本 3，兼容版本 1、2。Java 仍仅承担生命周期、权限、通知和 Surface 桥接。

## 页面主题

主程序采用 Neverlose 风格的深蓝黑面板、青蓝强调色、细边框卡片和右侧开关。`ui/theme.*` 集中管理主上下文的配色、间距、圆角、卡片与开关；`ApplyTheme` 重置后按密度和系统字号缩放，重复应用不会累计尺寸。字体继续来自系统，品牌标记由 ImGui 几何绘制，无额外字体或图片依赖。悬浮窗使用独立上下文，保持 Classic MetalHUD 的配色和布局。

卡片在同一 ImGui 窗口内自动计算高度，使用分组和独立绘制通道处理背景，允许嵌套；不会创建抢走页面拖动的子滚动区。边距对齐整像素，避免滚动时内容高度抖动。开关整行可点击、长标签自动换行，保留稳定 ID、键盘导航和滑动取消语义。HUD 三个操作按钮在宽度不足时改为纵向排列，原生软键盘按可用宽度分配按键。

## 翻译与控件状态

- `ui/i18n.cpp` 是翻译目录，英文源文本作为稳定键，缺失翻译回退源文本。
- `ui::Text` 用于正文，`ui::Label` 附加稳定的 ImGui `###` ID，语言切换不会改变按钮、树节点等控件身份。长表单使用 `ui::FieldLabel`，标签单独换行，控件占满可用宽度。
- 语言由宿主解析，通过 `RenderFrame.language` 和配置绘制参数传给插件，没有可变全局语言服务。
- 导航、插件名称和说明、HUD 操作、配置表单、设备报告标签已本地化。驱动输出、shell 诊断、路径、包名与原始错误保留原文，便于排查；Metal HUD 的 FPS/Pre/GPU/Mem 技术标签保持经典外观。
- 新语言需要补充目录、语言选择和解析，并验证格式化参数及字形覆盖。当前未承诺阿拉伯文等复杂文字的塑形和双向排版；字形可加载不等于完整的语言排版支持。

## 自动选择当前系统字体

Android 10 / API 29 及以上通过官方 `AFontMatcher` 按 `sans-serif`、当前语言、实际 Unicode 字符匹配系统字体，保留返回的字体路径和 TTC 集合索引。函数由 `dlsym` 解析，APK 不会在 API 26–28 上链接不存在的字体 API。

旧版系统读取 `/system/etc/fonts.xml`，使用固定版本 TinyXML-2 10.0.0 解析 familyset、sans-serif 别名、语言、normal/400 字重及 TTC index。按系统字体家族与语言回退顺序合并字形。复用 ImGui 随带的 stb_truetype 验证字体和字形，只保留实际提供所需字形的字体数据。既不假设所有系统字体都是独立 TTF，也不固定把某个中文字体当作系统默认字体。

每个 ImGui 上下文独立拥有字体范围与图集。主界面使用系统字体及系统无障碍字号倍率；经典 HUD 数字继续使用随包等宽字体。图集预热完整翻译目录，再按设备报告、诊断和 Surface 名称中的新字符增补。需求以 Unicode 字符去重，使用 `IMGUI_USE_WCHAR32`，不把整套 CJK 字库预先装入 GPU。只有新增字形或字体配置变化才在帧边界等待 GPU、释放旧字体纹理、重建图集；不在绘制回调内修改 atlas。字体文件按 64 MiB 上限读取，失效来源被跳过；系统字体完全不可用时保留随包字体并显示回退状态。彩色 emoji、变体轴和复杂文字塑形仍受当前 ImGui/stb 后端限制。

## 验证

主机测试额外依赖 DejaVu Sans 和 Noto Sans CJK（Ubuntu：`fonts-dejavu-core fonts-noto-cjk`）。可通过 CMake 的 `TEST_LATIN_FONT`、`TEST_CJK_FONT` 指定测试字体路径；这些字体仅用于主机测试，不打包进 APK。TinyXML-2 源码和许可证已纳入仓库，构建不需要下载依赖。

`navigation_i18n_test` 覆盖系统/手动语言选择、未知键回退、报告值保留、控件 ID 稳定、系统字体 XML/TTC 索引、完整翻译目录字形、动态字形需求、底栏点击与横竖屏页面保持。可运行 `navigation_i18n_test /tmp/pages` 生成双页 PPM 预览（测试设备数据，使用实际 ImGui 导航、主题组件、主页插件绘制与字体）。

`navigation_touch_test` 覆盖两页手势滚动、固定底栏、独立滚动位置、按钮点击与滑动取消、滑块操作、触摸取消、边界钳制和鼠标滚轮，并验证卡片内开关点击与滑动取消。

真机仍需验证 OEM 自定义字体、API 26–28 字体回退、系统语言/字号切换、长设备名、横竖屏、系统栏和大字号布局，以及悬浮窗运行中反复切页和启停插件。
